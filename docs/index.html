Project Overview: A zero-build, kid-friendly daily calendar and reminder web application for two Lauremont School students (Sophia and Olivia) built from Google Classroom streams, school portal handbooks, and the official school calendar.

sequenceDiagram

    Scraper->>DB: CALL upsert_raw_item(...)

    Note over Scraper: LLM extracts structured event JSON
    Scraper->>DB: CALL upsert_event(...)
    DB->>DB: Material change detected -> status='pending'
    DB-->>Scraper: Status: 'updated', material: true
    Scraper->>DB: CALL reconcile_deletions() & sync_chunks()

    Note over Parent: Moderation Step
    Parent->>DB: SELECT * FROM v_review_queue;
    Parent->>DB: UPDATE events SET status='published' WHERE id = ...

    Note over Client: Student opens app
    Client->>DB: GET /rest/v1/v_public_agenda
    DB-->>Client: Returns published events
    Client->>Client: Merges localStorage 'done' ticks and renders

Tech Stack & Design Philosophy

Zero-build architecture, performance considerations, and dependency trade-offs.

Technology Breakdown

LayerTechnologyPurpose & Justification
Frontend CoreVanilla JavaScript (ES6+)Zero bundlers or npm dependencies. Instant loading and long-term durability.
StylingModern CSS3 Custom PropertiesNative light/dark theming via prefers-color-scheme and per-kid accents.
PWA EngineCustom a2hs.js + Pass-through sw.jsCross-platform Add-to-Home-Screen banner without stale cache bugs.
DatabasePostgreSQL 15 (Supabase)Relational integrity, JSONB attachments, cryptographic hashing, and RLS.
API AccessPostgRESTAuto-generated REST endpoints directly querying PostgreSQL views.
ServerlessSupabase Edge FunctionsDeno/TypeScript runtime for gated AI conversational queries.
DeploymentGitHub PagesGit-driven deployment serving verbatim from the main branch root.
FingerprintingTracked Git Pre-Commit HookAuto-hashes staged CSS/JS files into ?v=hash without build tools.

Asset Versioning Workflow

Pre-Commit Cache Busting Engine
flowchart TD
    Commit["git commit"] --> Detect{"Did commit touch
a versioned asset?"}
    Detect -- No --> Allow["Proceed with commit"]
    Detect -- Yes --> CheckStaged{"Any unstaged edits
in HTML pages?"}
    CheckStaged -- Yes --> Abort["Abort: Prevent accidental staging"]
    CheckStaged -- No --> Hash["Calculate SHA hash of staged assets"]
    Hash --> Rewrite["Rewrite ?v=hash in all HTML entrypoints"]
    Rewrite --> Stage["git add modified HTML pages"]
    Stage --> Finish["Commit completed with synchronized ?v=hash"]

Data Ingestion & Extraction Pipeline

Automated Chrome collection, multimodal OCR, and deduplication logic.

Collector Execution Flowchart

Browser Ingestion Lifecycle
flowchart TD
    Start(["Cowork Cron Slot"]) --> RunInit["INSERT INTO collection_runs"]
    RunInit --> ScanStream["Navigate to Classroom Stream (Page 1)"]
    
    ScanStream --> ExtractPost["Extract Post Permalink & Metadata"]
    ExtractPost --> CheckAttach{"Attachment present?"}
    
    CheckAttach -- Yes --> ProcessAttach["Process Attachment:
- Docs/Slides: read as text
- Images/Scans: visual OCR in Drive"]
    CheckAttach -- No --> UpsertRaw
    ProcessAttach --> UpsertRaw
    
    UpsertRaw["CALL upsert_raw_item(...)"]
    UpsertRaw --> Status{"Raw Item Status?"}
    
    Status -- unchanged --> NextPost["Next Post"]
    Status -- created / changed --> LLM["Invoke Extraction LLM"]
    
    LLM --> UpsertEvent["CALL upsert_event(...)"]
    UpsertEvent --> Supersede["CALL supersede_missing_events(...)"]
    Supersede --> NextPost
    
    NextPost --> EndCheck{"More posts or courses?"}
    EndCheck -- Yes --> ScanStream
    EndCheck -- No --> Maintenance["End-of-Run Jobs:
1. expand_recurring_rules()
2. reconcile_deletions()
3. sync_chunks()"]
    
    Maintenance --> FinishRun["Update collection_runs: status='ok'"]
    FinishRun --> End(["Run Complete"])
